# MyAgent 1.3.0 使用说明

这次升级把资料、常用任务和生成成果接入正常对话。已有模型仍可直接使用，不要求重新填写服务地址或密钥。

## 从哪里开始

| 入口 | 用途 |
| --- | --- |
| 顶栏右侧时钟图标 | 打开任务中心，查看任务、恢复中断任务、定时任务与监控、MCP、备份迁移 |
| 回复中的文件卡片「预览」 | 文档预览、编辑、版本比较与恢复、表格计算 |
| 设置 →「模型配置」 | 用四个标签统一管理对话、图片、视频、服务连接和语音 |
| 左栏历史列表 | 直接查看全部对话，搜索、重命名、导出和删除 |
| ⌘/Ctrl + Shift + Space | 独立快捷对话窗口；可以取消或打开完整对话 |

## 配置只需填写一次

所有模型设置都在「设置 → 模型配置」，按用途切换标签：

| 标签 | 用途 |
| --- | --- |
| 对话与图片 | 添加、编辑模型，选择默认对话模型和图片模型；管理本地 CLI、HTTP 等生图工具 |
| 视频模型 | 管理 MiniMax Hailuo v1 视频配置 |
| 服务连接 | 共用服务地址和密钥，发现并添加模型 |
| 语音与回答 | 设置流式输出、听写、朗读、语音打断和快捷对话 |

更新后的应用启动并读取旧配置时，会自动整理可确认设置一致的旧对话模型，将它们关联到服务连接。原模型、密钥、协议、默认选中项及本地 CLI 参数保留；不适合自动整理的配置继续保留为独立配置。

新增多个同服务模型时，在「服务连接」填写一次地址和密钥，再发现模型或为模型选择该连接。删除服务连接会为关联模型保留当前有效配置。修改地址、协议、模型名或密钥后，旧诊断会自动失效。

保留一个默认对话模型，再选择独立的图片模型即可；本地对话、本地 CLI/HTTP 生图继续支持。对话协议支持 OpenAI 兼容和 Anthropic Messages。基础连接测试验证接口响应；完整诊断分别验证普通回答、历史消息、流式和工具调用，视觉测试需主动选择并实际识别图片。测试可能使用少量服务额度。

服务连接中的「发现模型」会读取服务实际返回的列表。同一服务已经添加的模型显示勾选和「已添加」，只需勾选其他模型即可新增，已有配置和默认模型保留。MiMo 的 O/A 对话配置均使用独立的官方模型列表接口，无需修改原聊天地址。空列表或发现失败会持续显示原因，并可重试；未提供列表接口的服务仍可手动填写模型名称。

## 对话与资料

左栏恢复为统一历史列表，点击「新对话」即可开始。没有项目分组、归属选择或项目规则。

旧项目下的历史消息、附件、收藏与分支保留，所有历史对话均可直接打开。旧项目规则和资料目录不再应用，也不会自动导入普通资料目录。之前明确配置的资料目录和新上传的附件继续可用。

工作空间及其记忆、配方和收藏入口已移除。旧记录仅作数据与备份兼容保留，不再生成候选记忆或注入旧记忆；「记住」「忘掉」等请求直接发送给模型。切换对话继续保留未发送文字和附件，消息重新生成与历史分支切换仍可使用。

## 文件和数据

Word、PDF、Excel、Markdown、TXT、CSV 成果可以点击预览、打开或下载。文档工作台编辑提取正文或表格单元格，保存为新版本，原文件保留；历史版本可以比较、恢复和下载。PDF/Word 编辑后重新排版，不是保留任意原版式的文字替换。

PDF 提取标明页码；扫描件使用随应用分发的中英文离线 OCR，显示置信度和失败页。低置信度内容需核对，OCR 不等于人工校对。

Excel/CSV 支持指定 Sheet 和范围，筛选、去重、分组汇总、同比及图表。计算使用真实文件和十进制运算，返回来源和实际 XLSX/CSV/图表；读取期间源表变化则中止。公式使用文件中缓存值，缓存缺失会明确提示，不会伪造结果。

## 图片和视频

直接在对话中描述生图需求，生成结果可预览和下载；图库继续可用。图片工作台和「编辑 / 版本」入口已移除。模型配置中的生图选择区留出卡片、分隔线和控件间距，本地 CLI/HTTP 生图配置保留。

视频目前支持 MiniMax v1/Hailuo。任务会持久保存厂商任务 ID，中断后查询同一任务，避免重新付费提交。如果提交结果无法确认，会拒绝自动重提。停止本地等待不保证撤销厂商任务或费用；完成的视频可从对话或任务记录打开。

## 任务、外部工具和备份

任务记录保存状态、步骤与结果；已完成工具步骤恢复时复用。外部写操作结果不明时禁止自动重复，需先核对服务端，再明确发起新请求。

定时提醒、定时任务、网页变化和目录变化监控在应用运行时执行。退出或睡眠错过的任务会显示需处理，避免恢复后悄悄补做。网页监控依据原始 HTML 内容，动态页面可能频繁变化。

MCP 支持 stdio 和 HTTP。只有连接后列出的工具可用；写操作和未知操作需要批准本次调用，批准不可复用。取消、断开和超时会结束等待。

备份加密保存配置、对话、任务和应用管理的附件/生成成果/版本/索引，并兼容保留旧记忆、配方、收藏和项目元数据。恢复前显示冲突与警告，支持合并或替换，以及恢复前快照回滚。托管附件路径自动迁移；外部资料目录只保留引用，换机器后需要重新选择实际资料目录。恢复旧备份不会重新启用已移除的工作台或项目功能。备份密码无法找回。

## 本版明确范围

- 本地文件最大 80 MB；PDF 最多 100 页，OCR 存在识别误差。
- 单次表格计算最多 10,000 行、20 个步骤；图表最多 200 个数据点。超限会拒绝或明确提示，不把截断内容当完整结果。
- 超出安全整数范围的数据不自动转成不准确的数值；通用计算没有取代完整 Excel 公式引擎。
- 视频未接入 MiniMax H3/v2；其他厂商与模型能力以实际诊断和已实现适配为准。
- 语音听写依赖系统/已配置服务；系统朗读不依赖麦克风。自动模式简要朗读长回答，随时可打断。

## 安装与数据

1.3.0 沿用 `com.myagent.app`、`MyAgent` 和 `~/Library/Application Support/MyAgent`，版本和安装位置不会改变配置目录。覆盖安装后继续使用原配置；升级前自动保存快照。测试和验收均使用独立临时资料，没有读写实际用户配置。

已使用真实 1.2.0 安装包验证升级到 1.3.0：旧加密 API Key、模型及默认选中项、会话和消息分支完整保留，升级快照包含旧配置。

安装包为 Apple Silicon macOS 本地自签名构建，未进行 Apple 公证。
