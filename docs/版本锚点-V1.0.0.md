## 找回 1.0.0 归档基线（三种方式，任选其一）

| 方式 | 命令 | 适用场景 |
|---|---|---|
| **标签（推荐）** | `git fetch --tags && git checkout v1.0.0` | 只读对比、打 1.0.0 包 |
| **分支** | `git fetch && git checkout release/1.0.0` | 从 1.0.x 拉 hotfix 分支 |
| **提交哈希** | `git checkout 82f0b4dbff3994bdc8ca1ef850a70134f65f3b1f` | 标签/分支不可用时的兜底 |

校验当前检出是否为 1.0.0 基线：

```bash
git rev-parse HEAD
# 应输出 82f0b4dbff3994bdc8ca1ef850a70134f65f3b1f

grep '"version"' package.json
# 应显示 "version": "1.0.0",
```

确认 **main 在 1.0.0 之上继续开发**（而非分叉）：

```bash
git merge-base --is-ancestor v1.0.0 main && echo OK
git log v1.0.0..main --oneline   # 列出 1.1.0 相对 1.0.0 的新提交
```

## 打包区分

| 产品线 | 取码方式 | 版本号来源 | 产物标识 |
|---|---|---|---|
| **1.0.0** | `git checkout v1.0.0` 或 `release/1.0.0` | `package.json` → `1.0.0` | 安装包/关于页显示 1.0.0 |
| **1.1.0** | `git checkout main`（最新） | `package.json` → `1.1.0` | 安装包/关于页显示 1.1.0 |

构建命令（两线相同，版本由当前分支的 `package.json` 决定）：

```bash
npm run build
npm run package        # 或 package:mac / package:win / package:linux
```

## 回退到 1.0.0 代码

```bash
# 方式一：标签（推荐）
git fetch --tags
git checkout v1.0.0

# 方式二：锚点分支
git fetch origin
git checkout release/1.0.0

# 方式三：在任意分支上仅检出该提交（ detached HEAD，适合只读对比）
git checkout 82f0b4dbff3994bdc8ca1ef850a70134f65f3b1f

# 方式四：从锚点拉修 bug 分支
git checkout -b hotfix/1.0.x v1.0.0
```

回退后安装依赖并打包：

```bash
npm ci
npm run build
npm run package:mac   # 按平台选择
```
