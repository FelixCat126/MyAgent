## 打包区分

| 产品线 | 取码方式 | 版本号来源 | 产物标识 |

| **1.0.0** | `git checkout release/1.0.0` | `package.json` → `1.0.0` | 安装包/关于页显示 1.0.0 |

构建命令（两线相同，版本由当前分支的 `package.json` 决定）：

```bash
npm run build
npm run package        # 或 package:mac / package:win / package:linux
```

## 回退到 1.0.0 代码

```bash
# 方式一：切到锚点分支（推荐，用于修 1.0.x 或打 1.0 包）
git fetch origin
git checkout release/1.0.0

# 方式二：在任意分支上仅检出该提交（ detached HEAD，适合只读对比）
git checkout 82f0b4dbff3994bdc8ca1ef850a70134f65f3b1f

# 方式三：从锚点拉修 bug 分支
git checkout -b hotfix/1.0.x release/1.0.0
```

回退后安装依赖并打包：

```bash
npm ci
npm run build
npm run package:mac   # 按平台选择
```
